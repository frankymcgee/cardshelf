ORIGINAL SYNTHESIZED AUDIO
Quiet table (32 seconds) and Pulse table (24 seconds), plus attack, knockout,
coin, turn, victory and defeat cues, were generated specifically for this
CardShelf update. These are original synthesized recordings, not downloads
from Kenney or extracts from any commercial game soundtrack.
No third-party samples, performer recordings or borrowed melodies were used
in these generated files. They are supplied for use and modification with
this project. No external licence fee, API service or streaming account is needed.

All playback is self-hosted from /audio/arena/. Preferences are local to the
browser. Audio stays silent until the player explicitly enables it, and is
stopped on navigation, loss of arena access, or window/tab deactivation.
See manifest.json for file hashes.

ADDITIONAL ORIGINAL CUES — 0.52.4
Draw, Energy attachment, Bench play, evolution, Trainer play, switching/retreat,
Prizes, abilities/Stadium activation, healing, condition/effect damage,
missed attacks and deck shuffling each have a distinct short cue.
Reproduce these twelve WAVs with: python3 scripts/generate-arena-effects.py
The generator uses only mathematical oscillators and seeded noise; it requires
the Python standard library only. Existing interface samples/music remain intact.
Runtime playback uses the bundled files, never Python or an external service.
