# Portfolio and binder completion estimates

## Collection overview

The collection's existing AUD estimate now has a compact 7/30/90-day trend.
Missing days and unpriced observations remain gaps. Period change describes
recorded collection value, with price/currency movement and copies added/removed
labelled separately. It is not profit: purchase costs are not recorded.

Open **Portfolio insights** for estimated value by game and up to three gainers
and three decliners in the selected period. Movers compare the first and last
recorded observations within that window, using only retained copies with positive
prices and the same provider, finish, currency, metric and approximation status.
New purchases, removals and gained/lost coverage are not ranked as market moves.
The displayed dates and comparable-printing count explain limited history.
Game totals include the same labelled guide approximations and exclusions as the
collection estimate. Fully unpriced games have no numeric value.

The compact chart keeps the overview brief. The existing full graph, observation
slider, data table, change breakdown and pricing methodology remain under
**Value details & history**. Binders retain their existing Cards / Value & history
views. Portfolio values use owned inventory; planned binder values are separate.

## Complete this binder

Members with pricing access see a cached AUD estimate for acquiring one copy of
each missing printing. Repeated pockets do not multiply the cost. On Tracking
checklists, an unchecked target already in owned inventory is excluded from
purchase costs and labelled as needing a checklist update. Marks are unchanged.

The total follows the binder's targets, not a verified full master-set checklist.
It excludes postage, does not adjust for condition, and is not an available offer.
Exact-price, guide-reference, stale-price and FX rules match existing valuations.
Coverage is explicit: a partial total is labelled **Partial estimate**, entirely
unpriced purchases show **Not priced yet**, and no purchases needed is a real zero.
Available last-known guide values retain stale/failed-refresh warnings.

Each missing target shows its available source and estimate. **Order** offers
binder order, lowest estimate first and highest estimate first; unavailable prices
remain last. Sorting/searching does not change wishlist selections. Exact-printing
member listings and the existing bulk wishlist confirmation still work as before.

## Access, operation and validation

No migration, external price request or new provider is introduced. The completion
read uses the existing pricing cache and AUD rates in the same owner-only database
snapshot as the checklist. It does not refresh prices or write history. Members
without the `prices` capability receive neither pricing totals nor per-target
estimates from completion. Public binder links expose no portfolio, estimates,
private holdings or wishlist state. Other existing entitlements are unchanged.

The collection summary reuses existing private history boundaries. Only bounded
mover summaries are returned; raw saved holdings remain on the server. The worker
keeps its existing snapshot schedule. Pricing disabled means no new observations,
with saved history still available.

Validation covers retained-copy movements, provider/coverage changes, unknown
prices, FX gaps, repeated pockets, owned Tracking targets, private access and
pricing entitlements. Existing value-history, completion and compact-collection
browser suites exercise the built UI on desktop and phone, including light/dark
themes, price sorting, preserved selections and overflow checks.
